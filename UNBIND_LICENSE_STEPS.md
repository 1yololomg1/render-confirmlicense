# How to Unbind License from Machine

You're on machine `dd412e475cf838e7` but the license `dfc2077dbbad862a` is bound to `a276012a0584`.

## Quick Fix: Unbind in Admin Panel

1. **In the admin panel**, find license `dfc2077dbbad862a`
   - It should show in the list (you already have it open)
   - It shows "Bound" to machine `a276012a0584`

2. **Click "View"** on that license to see details

3. **Click "Unbind Machine"** button
   - This will remove the machine binding
   - The license will become "Unbound"

4. **Go back to the CONFIRM application** and try activating again
   - The license will now bind to your current machine (`dd412e475cf838e7`)

## What This Does

- Removes the binding to `a276012a0584`
- Allows the license to be activated on any machine (including yours)
- The license will automatically bind to your machine on next activation

## Alternative: Use an Unbound Judge License

If you don't want to unbind your personal license, you can use one of the 12 unbound judge licenses instead - they're ready to use on any machine.
